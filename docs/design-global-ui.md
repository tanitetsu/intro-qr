# グローバル UI 設計（ピクトグラム優先）

## 目的

Intro QR は **全世界展開**を前提とする。将来的に **おおよそ 80 言語**のローカライズを想定する。

そのコストと品質を両立するため、**アプリが提供する UI の説明文は最小限**にし、**ピクトグラム（アイコン・視覚パターン）で意味を伝える**ことを **高い優先度**の設計原則とする。

## 非目的

- ユーザーが書く表示名・自己紹介・リンクタイトル・メモなどの **ユーザーコンテンツを翻訳しない**（各ユーザーが自分の言語で書く）。
- ピクトグラムだけで **法的同意・セキュリティ・エラー原因の詳細**まで完全に置き換えることは目指さない（そこは短い文言＋翻訳が残る）。

## 3 層の文言

| 層 | 例 | 方針 |
| --- | --- | --- |
| **A. 操作 UI（クローム）** | タブ、主要アクション、一覧の行アクション | **見えるラベルは付けない**。ピクトグラム＋状態（色・アクティブ・無効）で伝える。 |
| **B. 補助・フォーム** | フィールド名、プレースホルダ、空状態の一行 | **短く**。可能ならアイコン＋短ラベル。80 言語でもキー数を増やさない工夫（下記）。 |
| **C. 説明・例外** | 同意ダイアログ、QR 長すぎ、同期失敗、インナーブラウザ案内 | **必要最小の翻訳文**。段落は避け、箇条書き・1〜2 文。 |

新機能・画面追加時は **まず A で表現できるか**を検討し、文言キーを増やすのは最後の手段とする。

## ピクトグラムのルール

1. **一貫したアイコンセット**  
   タブ・共通アクションは Lucide 等の単一ファミリで統一（既存: `src/components/layout/TabIcons.tsx`）。

2. **意味の固定**  
   同じ操作は同じアイコン（共有＝共有マーク、削除＝ゴミ箱、編集＝ペン、など）。画面ごとに別アイコンにしない。

3. **色・形で状態**  
   アクティブタブ、破壊的操作、同期済みなどは **色・枠・ドット**で示し、文言に頼らない。

4. **リンク種別**  
   SNS はサービスロゴ／ファビコン、種別（関心・連絡先など）は **小さなアイコン**で示し、バッジの長いテキストラベルは避ける方向。

5. **文化依存アイコンに注意**  
   ジェスチャー・宗教・国旗だけに依存しない。ユニバーサルなメタファ（QR、歯車、ユーザー、カメラ）を優先。

6. **タップ領域**  
   アイコンのみでも **44px 前後のヒットエリア**を守る（モバイル前提）。

## アクセシビリティ（80 言語と両立）

- 画面上にラベルを出さなくても、**スクリーンリーダー用**には `aria-label`（または `aria-labelledby`）を付ける。
- その文字列は **i18n キーとして翻訳対象**になるが、**画面上の説明文キーとは別管理**でき、ユーザーには見えない。
- 重要操作は **アイコン＋確認モーダル**（モーダル内の短文は層 C）で誤タップを防ぐ。

## i18n の拡張方針（80 言語向け）

- 正本キー: `src/lib/i18n/messages.ts`（現状 `ja` / `en`）。
- **キー数を増やさない**ことがピクトグラム戦略の KPI に近い。新キーは「ピクトグラムで代替不可」と理由を付けて追加。
- ロケール追加時は **同じキーセット**を各言語に埋める（未翻訳は `ja` フォールバック等、実装時に統一）。
- 日付・数値は `formatDate` 等で **ロケール API** に寄せ、文言キーにしない。

## 現状との対応（2026-10）

| 項目 | 状態 |
| --- | --- |
| 下部タブ | アイコンのみ表示、`aria-label` で nav 文言（`AppShell`） |
| タブアイコン | QR / 編集 / アルバム / 設定（Lucide） |
| 翻訳 | UI 文言は `messages.ts`、ユーザーコンテンツは非翻訳 |

## 実装時チェックリスト（PR 用）

- [ ] 新しい **常時表示の日本語/英語ラベル**を増やしていないか
- [ ] 主要操作は **アイコンまたは既存共通アイコン**で表現できるか
- [ ] アイコンボタンに **十分なタップ領域**と **`aria-label`（i18n）** があるか
- [ ] 空状態・エラーは **1〜2 文**に収まっているか
- [ ] リンク・SNS は **視覚（サムネ・ロゴ）**で判別できるか
